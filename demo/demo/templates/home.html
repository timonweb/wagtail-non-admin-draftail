Draftail outside the Wagtail admin

This demo uses Wagtail's Draftail editor on ordinary Django form pages. Anyone can read the notes; log in to write or edit one with images, documents, embeds and links.

Images and documents uploaded from the editor are saved in the "Public uploads" collection, which you can browse in the Wagtail admin.

# Security

If you've found a security issue in this package, please report it privately through GitHub's
[private vulnerability reporting](https://github.com/timonweb/wagtail-non-admin-draftail/security/advisories/new) instead of
opening a public issue, so a fix can be prepared before the details are public.

Please include the affected version, the steps to reproduce the issue, and what an attacker could do with it.

For an overview of what the package's views allow and who can use them, see the
[access model](https://github.com/timonweb/wagtail-non-admin-draftail/blob/master/README.md#access-model) in the README.
